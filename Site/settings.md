\## Краткое описание работы DNS и HTTPS



\*\*DNS (Domain Name System)\*\* работает как адресная книга в интернете. Пользователи вводят удобные буквенные адреса (например, `ivan-petrov-2024.github.io`), но компьютеры для связи используют цифровые IP-адреса. Служба DNS автоматически переводит понятное имя в нужный IP-адрес сервера. Утилита `nslookup` позволяет вручную проверить это соответствие и увидеть, на какой именно сервер указывает домен.



\*\*HTTPS\*\* — это расширение протокола HTTP с поддержкой шифрования. Когда сайт работает по HTTPS, все данные (пароли, сообщения, вводимая информация) передаются в зашифрованном виде. Это защищает пользователя от перехвата данных. GitHub Pages предоставляет бесплатные SSL-сертификаты, которые активируются автоматически, благодаря чему на сайте включается безопасное соединение.
